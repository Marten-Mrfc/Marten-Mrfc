I grew up, that is the main reason this website needed a revamp.

## School project
At school (`'VWO year 3 in the netherlands'`) this site was written. It was for a school project that taught all students of that class how to build a simple Web Application. 

I was also given this assignment but already knew a bit more...

### Easy Route
As I knew a bit more, I also knew about **AI**. So 123 and the old site was generated. Although after the generation I gave it a little personal touch but in the modern day we live in now you 100% could see it was made with AI.

## Renew
So that brings us to the part were I would say: `Hey, what did you make?`.

### Framework
I rebuild the website from Svelte to [Astro](https://astro.build/). This had a single reason: [Astro](https://astro.build/) is just easier to work with for a simple `.md` files based project. 

Most of it was set-up by me first but than the styling was ported to AI again. The reason being: I don't like writing the CSS (:

### Features
While my old app had a lot of broken features, this new one actually has working features.

#### Projects
Starting of I have an actual [projects](/projects) section. I can now for each project write propper `.md` files specifying what the project is about and telling a little story.

#### Blog
Well this doesn't need much explaining. It is almost the same system as [projects](/projects) except of the loads of Front Matter projects has that blog hasn't.

#### Contact
The contact page actually doesn't contain a broken content form anymore. I stripped it away (:

## Ending
All things come to an end. The same was for my old website. Now I just hope to write a lot of blog/project posts on this website.

Thank you for reading!
